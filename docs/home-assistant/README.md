# Home Assistant

The Home Assistant integration has six progressive tools. Entity operations apply fresh Assist exposure authorization. Four authoring and evidence actions deliberately use endpoint-wide `mcp:use` plus the configured Home Assistant administrator token instead. Thread and Matter tools use separate fixed command and registry boundaries. Root help lists namespaces; namespace help lists actions and schemas.
